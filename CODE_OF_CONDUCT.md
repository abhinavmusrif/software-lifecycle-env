# Code of Conduct

This project follows a simple standard: be respectful, specific, and constructive.

## Expected Behavior

- discuss ideas and code with professional respect
- explain technical disagreements clearly
- assume good intent while still reviewing carefully
- keep issues and pull requests focused on the project

## Unacceptable Behavior

- harassment or personal attacks
- discriminatory language
- publishing private information
- intentionally submitting secrets, malicious code, or misleading benchmark results

## Enforcement

Maintainers may close issues, reject pull requests, or block participants who repeatedly violate these expectations.
