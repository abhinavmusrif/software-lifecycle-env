# Roadmap

Software Lifecycle Env is focused on small, deterministic tasks that feel like real engineering work.

## Near-Term

- Add deployment/release workflow task
- Add incident-response workflow task
- Add clearer examples for agent action loops
- Add lightweight unit tests around server endpoints
- Improve benchmark report formatting

## Medium-Term

- Add task-authoring guide
- Add benchmark task schema validation
- Add evaluation export format for comparing agent runs
- Add examples for multiple OpenAI-compatible providers

## Non-Goals

- No real private production logs
- No secrets or customer data
- No hidden network dependency during validation
- No arbitrary shell execution inside task grading
